# Website Portofolio / CV Dinamis — Muhammad Hafiz Fuadhi

Aplikasi web portofolio dan CV dinamis berbasis **Python (Flask)** dan **Bootstrap 5** yang dilengkapi dengan halaman dasbor pengelola (CRUD) dan penyimpanan berbasis JSON.

## Fitur Utama
- **Halaman Publik:** Menampilkan profil diri, riwayat pendidikan, keahlian (skills), dan portofolio proyek secara responsif.
- **Dasbor Pengelola (Admin):** Dilengkapi autentikasi login untuk mengelola seluruh isi portofolio (Create, Read, Update, Delete) secara langsung tanpa mengubah kode sumber.
- **Penyimpanan JSON:** Seluruh perubahan data otomatis tersimpan ke dalam file `data.json`.
